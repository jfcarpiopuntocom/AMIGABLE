## Post 2: Build in Public / Arquitectura Técnica

**Texto:**
¿Cómo se construye un sistema de inventario y gestión para tiendas físicas que no necesita servidor ni base de datos en la nube?

Con **AMIGABLE**, decidimos mantenerlo radicalmente simple:
1. **Un solo archivo HTML** con JavaScript vanilla dentro de `docs/`.
2. **Cero frameworks pesados**, cero bundlers obligatorios para leer o modificar el código.
3. **Service Worker + LocalStorage** para funcionar 100% offline en cualquier teléfono o tablet de mostrador.
4. Sincronización opcional con PocketBase para multi-dispositivo.

El resultado: una app que carga instantáneamente, no tiene costos mensuales de infraestructura, y le devuelve la paz al comerciante que antes dependía de un cuaderno o una hoja de Excel.
